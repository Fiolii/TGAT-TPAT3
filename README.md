# SIXENT – ติว TGAT / TPAT3 / A-Level

เว็บแอปล้วน (HTML/CSS/JS) ไม่ต้อง build ใช้งานบนคอมและมือถือ ติดตั้งเป็นแอปได้ (PWA) และใช้ออฟไลน์ได้หลังเปิดครั้งแรก

## เปิดบนคอม
```
node serve.js
```
เปิด http://localhost:5173

## เปิดบนมือถือ
1. **WiFi เดียวกัน (ทดลองเร็ว):** รัน `node serve.js` แล้วเปิดที่อยู่ "มือถือ (WiFi เดียวกัน)" ที่โปรแกรมแสดง
   (ถ้าเปิดไม่ได้ ให้อนุญาต Node.js ใน Windows Firewall) — โหมดนี้ติดตั้งเป็นแอปไม่ได้ เพราะไม่ใช่ HTTPS
2. **ใช้ได้ทุกที่ (แนะนำ):** อัปโหลดทั้งโฟลเดอร์ขึ้นโฮสต์ HTTPS ฟรี เช่น
   - Netlify Drop: https://app.netlify.com/drop (ลากโฟลเดอร์นี้ไปวาง)
   - GitHub Pages: สร้าง repo → อัปโหลดไฟล์ → Settings → Pages
   จากนั้นเปิดลิงก์บนมือถือ → เมนูเบราว์เซอร์ → "เพิ่มลงหน้าจอหลัก / Install app"

## แก้ไขเนื้อหา
- `data/meta.js` โครงสร้างข้อสอบ, `data/lessons.js` บทเรียนและแหล่งอ้างอิง
- `data/q_*.js` โจทย์ (ฟังก์ชัน `Q(id, group, subject, topic, diff, q, choices, answerIndex, explanation, {passage, fig, tip})`)
- แก้ไฟล์แล้วเปลี่ยน `VERSION` ใน `sw.js` เพื่อให้เครื่องที่ติดตั้งแล้วอัปเดต

## หมายเหตุ
- โจทย์ทั้งหมดเขียนใหม่ตามแนวข้อสอบ ไม่ใช่ข้อสอบจริงของ สทศ. (ลิขสิทธิ์)
- โครงสร้างข้อสอบอ้างอิงคู่มือปี 2022 ตรวจกับประกาศ สทศ./mytcas.com ก่อนสอบทุกครั้ง
- สถิติเก็บในเบราว์เซอร์ของแต่ละเครื่อง ใช้ปุ่มส่งออก/นำเข้าในหน้า "สถิติ" เพื่อย้ายข้อมูล
