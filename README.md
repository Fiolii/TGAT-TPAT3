# SIXENT – ติว TGAT / TPAT3 / A-Level

เว็บแอปล้วน (HTML/CSS/JS) ไม่ต้อง build ใช้งานบนคอมและมือถือ ติดตั้งเป็นแอปได้ (PWA) และใช้ออฟไลน์ได้หลังเปิดครั้งแรก

## เปิดบนคอม
```
node serve.js
```
เปิด http://localhost:5173

## เปิดบนมือถือ
1. **WiFi เดียวกัน (ทดลองเร็ว):** รัน `node serve.js` แล้วเปิดที่อยู่ "มือถือ (WiFi เดียวกัน)" ที่โปรแกรมแสดง
   (ถ้าเปิดไม่ได้ ให้อนุญาต Node.js ใน Windows Firewall) — โหมดนี้ติดตั้งเป็นแอปไม่ได้ เพราะไม่ใช่ HTTPS
2. **ใช้ได้ทุกที่ (แนะนำ):** อัปโหลดทั้งโฟลเดอร์ขึ้นโฮสต์ HTTPS ฟรี เช่น
   - Netlify Drop: https://app.netlify.com/drop (ลากโฟลเดอร์นี้ไปวาง)
   - GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`
   จากนั้นเปิดลิงก์บนมือถือ → เมนูเบราว์เซอร์ → "เพิ่มลงหน้าจอหลัก / Install app"

## ฟีเจอร์หลัก
- 🫧 หน้าตาแบบกระจกใส (liquid glass): พื้นผิวโปร่งแสงเบลอฉากหลัง แถบบน/ล่างลอยแบบแคปซูล การเคลื่อนไหวแบบสปริง รองรับโหมดสว่าง/มืด ธีมมหาวิทยาลัย และมือถือ — สไตล์ทั้งหมดอยู่ใน `glass.css` (ลบบรรทัดที่โหลดไฟล์นี้ใน index.html เพื่อกลับเป็นหน้าตาเดิม)
- ข้อมูลทางการจาก mytcas.com (ทปอ.): ปฏิทิน TCAS70 และ blueprint ทุกวิชา (`data/tcas.js`)
- หลักสูตรรายบท 70 บท / 317 สไลด์ ตามโครงสร้าง blueprint (`data/course_*.js`): สูตร ตัวอย่างทำให้ดูทีละขั้น กับดัก ซิมูเลเตอร์ และแหล่งอ้างอิง
- ธีมสีตามมหาวิทยาลัยวิศวะ 10 แห่ง + โหมดสว่าง/มืด (กดปุ่ม 🎨 ที่แถบบน) — ข้อมูลสีใน `data/themes.js`
- โจทย์ A-Level แบบ "ตอบเป็นตัวเลข" เหมือน 5 ข้อท้ายของข้อสอบจริง (`data/q_num.js`)
- ข้อสอบแบบสมุดทีละหน้า (โหมดฝึกเฉลยทันที / โหมดสอบจำลองจับเวลา) พร้อมเฉลยละเอียดและ "ทำไมข้ออื่นถึงไม่ใช่"
- โจทย์มิติสัมพันธ์ เฟือง สายพาน รอก ที่สร้างด้วยโค้ด (คำนวณเฉลยโดยโปรแกรม)
- บทเรียนแบบสไลด์ + ซิมูเลเตอร์โต้ตอบ + แหล่งอ้างอิงที่ตรวจแล้ว
- 🎯 ภารกิจรายวัน: เปิดแอปมาระบบเลือกโจทย์ให้ 5–20 ข้อ/วัน (เน้นข้อที่เคยผิด/ยังไม่เคยทำ/หัวข้อที่ยังอ่อน) + บทเรียนแนะนำ + เป้าเวลา สตรีคนับวันติด (`data/daily.js`)
- 🧑‍🏫 ตัวอย่างบนกระดานดำ 3 ระดับทุกบท (ในห้องเรียน / ข้อสอบจริง / สอวน) — เปลี่ยนระดับแล้วครูเปลี่ยนเป็นบุคคลสำคัญของเนื้อหานั้น (เช่น กาลิเลโอ→นิวตัน→ไอน์สไตน์ในบทการเคลื่อนที่) ครูทุกคนเป็นการ์ตูน SVG วาดเอง ข้อมูลอยู่ใน `data/people.js` และ `data/lv_*.js`
- 🖍 ทุกกระดานทั้ง 3 ระดับ (287 ข้อ) มีภาพประกอบที่ครูวาดทีละขั้นเหมือนระดับห้องเรียน ตัวเลขในภาพคำนวณจากโจทย์ของข้อนั้น แตะที่ภาพเพื่อขยายเต็มจอ (เลื่อนดูได้) — ชุดเครื่องมือวาดอยู่ใน `data/lv_figs.js` และภาพของแต่ละวิชาอยู่ใน `data/lv_fig_*.js` (ลงทะเบียนด้วย `LF('รหัสบท','exam'|'olym',ลำดับข้อ,กว้าง,สูง,H=>[กลุ่มภาพของแต่ละขั้น])`)
- 🎓 เลือกมหาวิทยาลัย 10 แห่ง: เปลี่ยนทั้งสี ตราสัญลักษณ์ (วาดเป็น SVG เอง ไม่ใช้อีโมจิ) ลวดลาย คติพจน์ เสื้อช็อป และเปิดหน้า "รู้จักมหาวิทยาลัย" — เด่นด้านอะไร มีคณะอะไร และประวัติคณะวิศวกรรมศาสตร์ (ปีที่ตั้ง ใครริเริ่ม เส้นเวลา) ข้อมูลสรุปจาก Wikipedia ไทย; วางตราจริงไว้ที่ `icons/uni/<id>-logo.png` เพื่อใช้แทนตราที่วาดเอง
- 👕 เสื้อช็อปของฉัน: ตั้งชื่อเล่น สะสมแต้มเลื่อนชั้นปี (ปี 1 → วิศวกรมืออาชีพ) และแพทช์ติดเสื้อ + คำคม/มุกวิศวะประจำวัน (แตะโลโก้ 5 ครั้งมีเซอร์ไพรส์)
- 🏆 ระบบความสำเร็จ 35 รายการ (ปุ่ม 🏆 บนแถบบนและการ์ดหน้าแรก) คำนวณจากสถิติจริง ปลดล็อกแล้วมี toast — `data/ach.js`
- ∫ แคลคูลัสแบบละเอียด 6 บทย่อย (4.2–4.7: ลิมิต, ความต่อเนื่อง, อนุพันธ์, การประยุกต์, ปริพันธ์ไม่จำกัดเขต, ปริพันธ์จำกัดเขต/พื้นที่) พร้อมพิสูจน์ + โจทย์ใหม่ 23 ข้อ — `data/course_calc.js`, `data/q_calc.js`
- 📖 บทเรียนแบบบทความทุกบท (76 บท): ย่อหน้ายาวอ่านต่อเนื่อง กล่องสูตรที่ระบุตัวแปร ความหมาย และหน่วย ภาพประกอบ SVG วาดเอง 
- 👩‍🏫 ตัวอย่างบนกระดานดำ: ครูวาดภาพประกอบทีละขั้นพร้อมอธิบายละเอียด (กดทีละขั้นหรือดูทั้งหมด) และหน้า "จุดตาย" ของแต่ละบท — โค้ดใน `data/art.js` `data/read_*.js`
- 🧪 "ที่มาของสูตร" 46 สไลด์พิสูจน์/พิสูจน์สูตร (ฟิสิกส์ เคมี คณิต TPAT3 ตรรกะ) แทรกก่อนสไลด์กับดักของแต่ละบท — ข้ามได้ (`data/proofs.js`)
- แหล่งอ้างอิงแสดง "ภาษาไทยก่อน" (Wikipedia ไทย, PhET หน้าไทย, สสวท. Learning Space, Khan Academy ไทย, ทรูปลูกปัญญา) แล้วตามด้วยแหล่งภาษาอังกฤษ — แมปชื่อบทความใน `data/thwiki.js`
- สถิติ จับเวลา Pomodoro บันทึกผลสอบเก่า นำเข้าโจทย์เอง

## แก้ไขเนื้อหา
- `data/meta.js` โครงสร้างข้อสอบ, `data/lessons.js` บทเรียน/แหล่งอ้างอิง, `data/slides.js` สไลด์ที่ผูกกับซิมูเลเตอร์
- `data/q_*.js` โจทย์ — `H(id, หัวข้อ, ระดับ, โจทย์, ตัวเลือก[5], เฉลย(index), วิธีทำ, why[5], {tip, fig, passage})`
  (`why` = เหตุผลที่ตัวเลือกอื่นผิด แสดงหลังเฉลย)
- `data/figs.js` + `data/q_spatial.js` สร้างโจทย์ภาพด้วยโค้ด
- `sim/*.js` ซิมูเลเตอร์ (canvas/SVG/CSS 3D) ลงทะเบียนด้วย `SIMS[ชื่อ]`
- แก้ไฟล์แล้วเปลี่ยน `VERSION` ใน `sw.js` เพื่อให้เครื่องที่ติดตั้งแล้วอัปเดต
