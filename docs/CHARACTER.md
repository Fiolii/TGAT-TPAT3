# ระบบตัวละครแต่งตัว (ชิ้นส่วนแยกเลเยอร์)

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `assets/char/pf/*.png` | ชิ้นส่วนผู้หญิง (PNG พื้นโปร่งใส ตัดจากแผ่นของผู้ใช้) |
| `assets/char/pm/*.png` | ชิ้นส่วนผู้ชาย |
| `data/char_png_dims.js` | ขนาดภาพของแต่ละชิ้น (กว้าง,สูง) |
| `data/char_png.js` | รายการไอเทม `PNGSET`, ลำดับเลเยอร์ `AV_LAYERS`, จุดอ้างอิง `A`, ตัวประกอบ `avatarSvg` |
| `data/char.js` | แคตตาล็อกไอเทม ราคา เหรียญ และหน้าแต่งตัว/ร้านค้า |
| `data/char_core.js`, `char_art.js`, `char_gear.js` | ตัวละครเวกเตอร์เดิม + เสื้อช็อป/ชุดเทศกาล/ฉาก/เอฟเฟกต์ (วางซ้อนบนตัวละครใหม่ได้) |

## ลำดับเลเยอร์ (ล่าง → บน)
`pet → hairBack → legs → shoes → body → armL → armR → bottom → shirt → outer → neck → head → eyes → hairFront → hacc → glasses → hat → hand`

- ทุกเลเยอร์เป็น `<g class="ly ly-ชื่อ" data-layer="ชื่อ">` ใน SVG เดียว ซ่อนได้จากปุ่ม "🧩 เลเยอร์" (เก็บใน `cfg.hide`)
- ผมถูกวาดสองชั้นจากภาพเดียว: `hairBack` (เต็มใบ อยู่ใต้ตัว) และ `hairFront` (ตัดเฉพาะส่วนเหนือคาง)
- ผู้ชายใช้ภาพลำตัวพร้อมแขน (`torso`) ชั้น armL/armR ของผู้ชายจึงว่าง · ผู้หญิงใช้ภาพลำตัวกับแขนแยก
- ผู้หญิงและผู้ชายใช้ฐานลำตัวคนละแบบ และมีจุดอ้างอิง (`A.f`, `A.m`) กับผืนผ้าใบของตัวเอง (หญิง 243×420, ชาย 310×705)
- ข้อจำกัด: ใบหน้าผู้หญิง (ตา คิ้ว ปาก) อยู่ในภาพเดียวต่อหนึ่งแบบ ส่วนผู้ชายแยกดวงตาเป็นเลเยอร์ `eyes`

## วิธีเพิ่มไอเทมใหม่ (ภาพ PNG)
1. ใส่ไฟล์ PNG พื้นโปร่งใสที่ `assets/char/pf/` (หญิง) หรือ `pm/` (ชาย) ตั้งชื่อเช่น `t_newshirt.png`
2. เพิ่มขนาดใน `data/char_png_dims.js` (`"t_newshirt": [กว้าง, สูง]`)
3. เพิ่มบรรทัดใน `PNGSET` ของ `data/char_png.js` ตามช่อง: `['t_newshirt', 'ชื่อไทย', ราคา]` (ช่อง `hair fc top bottom legs shoes hacc head neck face hand pet`)
4. ปรับตำแหน่ง/สเกลเฉพาะชิ้น (ถ้าจำเป็น) ในส่วนที่วาดช่องนั้นของ `avatarSvg` เช่น ผมใช้ `HOFF` เลื่อนขึ้นลง
5. รีเฟรชหน้า — ไอเทมโผล่ในหมวดและร้านค้าเอง (ราคา 0 = ฟรี)

## วิธีเพิ่มไอเทมแบบเวกเตอร์
เขียนฟังก์ชันคืนสตริง SVG ใน `AVX.<ช่อง>.<ชื่อ>` (`data/char_gear.js`) แล้วเพิ่มบรรทัดแคตตาล็อกใน `data/char.js`
